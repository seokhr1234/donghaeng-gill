# 고대비 모드·Android 1.0.3 — 2026-11-17 KST

사용자 요청으로 웹·확장 지도·단일 HTML·Android 공통 화면에 **고대비 모드**를 추가했다. 화면 위 **◐ 고대비** 버튼으로 켜고 끈다. 흰 바탕/검정 글자·분명한 테두리·파란 경로/링크·노란 주의 영역을 사용하며 전체 화면 색상 반전 필터는 사용하지 않는다.

## 조작과 표시

- 버튼은 키보드 Tab/Space/Enter로 조작하며 `aria-pressed`로 상태를 알린다. 선택은 `donghaeng.display.contrast`에만 저장하고 서버에 보내지 않는다. 페이지 재실행·확장 화면·같은 출처의 다른 탭에서 공유한다. 저장이 막히면 현재 창에서 작동하고 저장 실패를 알린다.
- 선택이 없으면 시스템 `prefers-contrast: more`를 따른다. 명시적으로 끈 선택은 시스템 기본값보다 우선한다. 운영체제의 강제 색상은 브라우저에 맡기며 버튼·기호·범례를 유지한다.
- 입력창·버튼·메뉴·지도 조작·팝업·경고·출발/도착 핀에 대비를 적용한다. 배경 타일만 회색조/대비 조정하며 경로·시설·문자 기호는 그 필터 밖에 있다. 샘플링한 주요 글자 요소의 대비는7:1 이상이다. 지도 타일 전체 글자나 모든 상태를 포함한 WCAG 적합성 인증·임상 색각 검사를 뜻하지 않는다.
- 선택 경로는 굵은 실선, 다른 경로는 긴 파선, 등록 경사 주의는 짧은 파선, 추정/자료 차이는 굵은 긴 파선, 구조물/접속 미확인은 점선, 급경사 참고 자료는 일점쇄선이다. **시설·지도 → 고대비 지도 범례**에서 설명을 연다. 기존 시설 SVG 기호와 승/하 문자·출/도 표시를 유지한다.
- 오스코의 횡단·출입·정류장·시설 점은 글자/도형으로 식별한다. 겹치는 지점은 화면32px격자로 묶어 숫자로 표시하고 팝업에서 원본 항목을 확인한다. 표시 위치는 첫 원본점이며 좌표 평균/보정·동일 시설 판정을 하지 않는다. 기본 모드로 돌아가면 기존 표시로 복원한다.
- 모드 전환은 경로 재계산/API 호출 없이 기존 벡터의 표시만 바꾼다. GPS 신호 품질의 낮은 불투명도는 유지한다. 출처·등록/추정/미확인·현장 미검증도 유지하며 안전 판정을 바꾸지 않는다.

## 접근성·빌드 보완

이용 안내의 ‘길 찾기 시작하기’가 숨겨진 목적지 입력에 초점을 보내던 문제를 수정했다. 현재 질문형 UI의 첫 질문 제목으로 초점을 보낸다. 기존 메인 검사도 질문창·통합 시설 패널·접힌 도움말의 실제 구조에 맞게 갱신했다. Android lockfile의 두 의존성 버전 표기 불일치도 실제 고정된 배포 URL/무결성에 맞춰 바로잡았으며 의존 패키지를 올리지 않았다.

`high-contrast.js/css`와 각 지도 객체의 표시 역할을 추가했다. Node 정적 허용 목록에 정확한 새 파일명을 등록했다. 기존11개 런타임 자료·연구·서울 그래프·표고/경사 자산과 엔진/위치 정책은 바이트 단위로 보존한다. 보호된 표시 코드와 서비스 해시는 원본 보존·실제 화면·오류·기존 기능 검사를 근거로 갱신하며 빌드 검사를 우회하지 않는다. 단일 HTML5개도 같은 소스로 생성한다.

## 검증·한계

- [고대비 UI 검사](high-contrast-ui-results.json): 실제 서울 경로의 표시 변경/복원과 좌표 불변, 키보드·상태 알림, 설정 저장/재시작/탭 동기화, 시스템 기본값/수동 해제/강제 색상/저장 차단, 오스코 기호와320/393px·가로 화면·확장/단일 HTML.
- [원본 보존·해시·동일 HTML](high-contrast-integrity.json), 기존 서울/오스코/도보 전용 API·내비게이션 코어·메인/GPS 모의 회귀 검사. 유료 공급자를 새로 호출하지 않는다.
- [Android 프런트엔드](android-demo-results.json): APK 자산에서 고대비와320px의 교통 키/모드 버튼, 기존 네이티브 통신 모의 검사를 수행한다. 실제 Android 휴대폰 설치·색각 사용자 평가·GPS·현장 통행은 별도다.

Android는 **1.0.3 / versionCode4**, 패키지 `app.donghaeng.gill.demo`다. 이전1.0.2와 같은 로컬 서명/네이티브 Android 키를 사용한다. 키·서명 설정·keystore는 Git/웹/로그에 포함하지 않는다. 최종 APK·푸시·Vercel·다운로드 검증은 게시 결과에 기록한다. 공개 웹은 도보 전용이고 Android 대중교통 시연은 그대로다.
