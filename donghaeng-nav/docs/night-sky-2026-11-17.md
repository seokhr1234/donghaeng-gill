# 밤하늘 고대비 정정 — 2026-11-17 KST

사용자가 Windows 고대비 ‘밤하늘’ 화면을 제시하며 흑백 UI/지도와 숫자의 안쪽 사각 테두리를 지적했다. 기존 구현의 흰 배경과 지도 회색조 필터는 요청한 모습과 달랐다. `high-contrast.css`의 숫자 자식span까지 적용된 테두리가 원형 묶음 표시 안에 사각형을 만들었다.

## 수정

- 고대비를 **검정 배경·흰 본문·노란 버튼/테두리·보라색 선택 상태·밝은 링크**로 바꿨다. 상단 버튼은 켜졌을 때 **◐ 밤하늘**로 표시한다. 기본 모드와 저장 키/기존 선택은 유지한다.
- Windows 강제 색상이 켜져 있으면 `Canvas`, `CanvasText`, `ButtonText`, `LinkText`, `Highlight` 등 실제 운영체제 색을 따른다. 일반 브라우저/Android에서는 제공된 스크린샷을 기준으로 한 밤하늘 팔레트를 사용한다. 확대/축소 버튼과 경고/팝업도 같은 테마를 적용한다.
- 지도 타일의 회색조/대비 필터를 제거했다. 온라인 타일과 내장 지도는 원래 색으로 표시하며 지도 타일에는 `forced-color-adjust:none`을 적용한다. 조작부만 테마를 적용하고 경로 선 모양은 유지한다.
- 서울 시설 묶음은 바깥 원형 표시 하나만 두고 **숫자span의 테두리·그림자·배경을 제거**했다. 작은 숫자b에도 안쪽 사각 테두리를 만들지 않는다. 오스코 숫자 묶음도 원형으로 표시하며 문자 지물/출발·도착 핀의 구분은 유지한다. UI 버튼/키보드 초점의 테두리는 남긴다.
- Android는 **1.0.4 / versionCode5**, 패키지는 `app.donghaeng.gill.demo`다. 기존 서명/네이티브 Android키로 업데이트하며 웹 도보 전용과Android 대중교통 시연 분리를 유지한다.
