# 밤하늘 고대비 정정 — 2026-11-17 KST

현재 배포 대상은 **밤하늘 + Gemini 입력 1.0.4 공개용(고정 키 없음)**입니다. ODsay는API설정에서입력하며Gemini는개인키입력또는기존서버를사용합니다. 아래키포함미게시빌드와보류기록은중간상태입니다. 최종공개용은17,926,946bytes·SHA256 `aa3f3129ed322be6f6a77f441fa6fa91db615c50bffb5037e9957479c49977b1`입니다.

사용자가 Windows 고대비 ‘밤하늘’ 화면을 제시하며 흑백 UI/지도와 숫자의 안쪽 사각 테두리를 지적했다. 기존 구현의 흰 배경과 지도 회색조 필터는 요청한 모습과 달랐다. `high-contrast.css`의 숫자 자식span까지 적용된 테두리가 원형 묶음 표시 안에 사각형을 만들었다.

## 수정

- 고대비를 **검정 배경·흰 본문·노란 버튼/테두리·보라색 선택 상태·밝은 링크**로 바꿨다. 상단 버튼은 켜졌을 때 **◐ 밤하늘**로 표시한다. 기본 모드와 저장 키/기존 선택은 유지한다.
- Windows 강제 색상이 켜져 있으면 `Canvas`, `CanvasText`, `ButtonText`, `LinkText`, `Highlight` 등 실제 운영체제 색을 따른다. 일반 브라우저/Android에서는 제공된 스크린샷을 기준으로 한 밤하늘 팔레트를 사용한다. 확대/축소 버튼과 경고/팝업도 같은 테마를 적용한다.
- 지도 타일의 회색조/대비 필터를 제거했다. 온라인 타일과 내장 지도는 원래 색으로 표시하며 지도 타일에는 `forced-color-adjust:none`을 적용한다. 조작부만 테마를 적용하고 경로 선 모양은 유지한다.
- 서울 시설 묶음은 바깥 원형 표시 하나만 두고 **숫자span의 테두리·그림자·배경을 제거**했다. 작은 숫자b에도 안쪽 사각 테두리를 만들지 않는다. 오스코 숫자 묶음도 원형으로 표시하며 문자 지물/출발·도착 핀의 구분은 유지한다. UI 버튼/키보드 초점의 테두리는 남긴다.
- Android는 **1.0.4 / versionCode5**, 패키지는 `app.donghaeng.gill.demo`다. 기존 서명/네이티브 Android키로 업데이트하며 웹 도보 전용과Android 대중교통 시연 분리를 유지한다.

## 후속 사용자 지시 — Gemini 입력과 APK 게시 진행

사용자가 키 적용 여부를 질문하고 APK 게시 진행 및 Gemini API 키 입력 방법을 요청했다. [Android API 설정](android-gemini-settings-2026-11-17.md)을 최종1.0.4에 추가했다. ODsay 내장 키와 서버/기기Gemini를 구분하고 내장 키 복원·개인 Gemini 저장/삭제를 제공한다. 앞선 게시 보류는 당시 상태이며 후속 요청에 따라 이번 ODsay키 포함APK 게시를 진행한다. 원시 비밀 값과 Gemini 개인 키를 공개 소스/웹에 넣지 않는다. 실제 Gemini서버 상태 조회는configured:true였으나 공급자 추가호출은0이다.

Gemini 입력 기능을 포함해 재빌드한 최신APK는17,926,782bytes, SHA256 `c61129e58e981fc7733cf8397c9acdb810feb70ff9842c14845e2b36771053a2`다. 위17,922,714bytes는 Gemini 입력 기능 추가 전 미게시 빌드이며 배포에 사용하지 않는다.


## 자동 승인 검토 후 공개용 빌드로 전환

공개키내장APK 업로드는자동승인검토가자격증명노출을이유로거부했으며그작업은실행되지않았다. 앞선 사용자 게시 진행 지시/키포함 빌드는 당시중간상태로보존하고, 실제배포는 **내장키없는공개용APK**로진행한다. 공개용Gradle기본값은 `donghaengEmbedOdsayKey=false`이고검사기는실제기존키가APK의모든압축해제항목에없음을확인한다. API설정에서ODsay/Gemini를기기에입력하며Gemini개인키미입력시Vercel서버를사용한다. 새공개파일과로컬키포함중간빌드는분리한다. 최종공개용크기/해시는검사결과및최종게시기록을기준으로한다.
