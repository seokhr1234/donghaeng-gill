# 청주오스코 지도 연결·Android 1.0.2 — 2026-11-17 KST

사용자 요청에 따라 사전조사 자료를 앱에 연결하고 커밋·푸시·APK 생성을 진행한다. 공통 앱 소스는 `donghaeng-nav/dist/`이며 웹은 도보 전용, Android는 네이티브 대중교통 시연을 유지한다. 연구 원본은 수정하지 않는다.

## 앱에서 확인하는 방법

- 지도 상단 **청주오스코** → **시설·지도 / 오스코** 탭에서 행사장·오송역과 등록 지물을 확인한다. 웹 기본 화면은 서울을 유지하며 `/?area=osco`로 행사장 주변을 바로 열 수 있다. Android 1.0.2는 오스코 주변으로 시작한다.
- **행사장·공식 안내**에서 공식 대표 위치, BF 본인증 우수 8244호, 공식 시설 가이드 PDF와 주차 안내를 연다. 주차991/1114대 차이와 수집일·자료 기준일·페이지 수정일·현장 미확인을 구분한다. 출입구가 검증된 좌표로 표시하지 않는다.
- 등록 보행로/계단·횡단/출입·정류장/철도·휴식/화장실/주차·건물 윤곽을 개별 선택한다. 기본은 꺼짐이다. 16~17단계 이상 확대했을 때 현재 화면에 최대600개를 표시한다. 원본 OSM 좌표·태그·객체 버전·갱신 시각은 보존한다. 정밀 실측 지도나 접근성 인증 경로로 표시하지 않는다.
- 청주오스코/오송역은 출발지·목적지 검색과 지도 선택을 지원한다. Android에서는 대표점으로 대중교통 참고 검색을 요청할 수 있다. 청주 도보 경로망은 연결하지 않아 도보 검색은 API/AI 호출 전에 지원 범위를 안내한다. 오송역 대표점·철도역8번출입구·‘오송역8’ 버스정류장은 구분한다.
- 지도 패널을 다시 열 때 모바일 입력창을 접고, 오스코 자료를 독립 탭으로 분리해 기존 정밀자료 파일 입력과 섞이지 않게 했다. 추가 자료가 실패해도 기존 서울 길찾기를 유지한다. 잘못된 스키마 응답을 거부하고 다시 원본을 요청할 수 있다.

## 자료 적용과 보류

`prepare-osco-map.py`는 보존된 연구 검증표의 SHA256과 지물 유효성 결과를 확인한 뒤 `data/osco/info.json`, `context.json`을 만든다. ODbL OSM5종의 모든 지물은 원본 추출본과 동일하며 UI는 그중 목적에 맞는 태그만 선택 표시한다. 범주 간 같은 지물이 겹칠 수 있으므로 합계를 실제 시설 수로 해석하지 않는다. 공식 문서 자체는 복제 배포하지 않고 사실 요약과 원문 링크를 제공한다.

청주시 도형5,462개와 가공 쉼터/화장실 상세행은 재이용 조건이 미확인이라 앱 배포에 넣지 않았다. Copernicus30m DSM을 보도 노면 경사로 변환하지 않았고 새 경사값/경로 연결/현장 검증은0건이다. 기존 서울 도로·표고·시설·정밀지도9개 데이터셋과 서비스 그래프/경사 자산은 바이트 단위로 보존했다.

`runtime-integrity.json`과 서비스 해시는 새 자료의 원본 대조·UI/실패/기존 기능 검사를 근거로 명시적으로 갱신했다. 보호 검사와 빌드 게이트를 유지하며 단일 HTML5개에도 같은 자료를 내장한다. 큰 오스코 도형은 필요할 때 해제한다. 로컬 Node 서버는 새 JS/CSS와 정확한 두 JSON 경로만 추가 허용한다.
