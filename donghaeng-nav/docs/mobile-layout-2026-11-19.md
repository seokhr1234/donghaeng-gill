# 모바일 화면 개선 · 2026-11-19 KST

갤럭시 S22+의 Android 1.0.4 녹화에서 API 설정이 헤더 공간을 차지하고, 삼성 키보드가 열린 동안 출발지 입력란과 다음 버튼을 함께 보기 어려웠다. 브라우저 모의 화면에서는 지도 연결 상태가 오스코 탭을 덮었고, 시설 패널이 장소 선택 버튼을 가렸다. 844×390 가로 화면에서 서울 도보 경로가 지도 밖으로 밀리는 사례도 재현했다.

- Android에서는 상단 **더보기(⋯) → API 설정**으로 ODsay와 Gemini 키를 관리한다. 서비스 상태와 입력 버튼을 먼저 보여 주고, 키 발급 및 정보 전송 안내는 펼쳐서 읽는다. 기기에 저장한 Gemini 키가 있을 때 삭제 동작을 표시한다. 설정에서 나오면 더보기 메뉴로 돌아간다.
- 질문창은 현재 단계의 내용만 스크롤한다. 진행 버튼은 별도 영역에 두고, 입력 중에는 실제 표시 높이에 맞춰 하단 탭과 캐릭터를 접는다. Android Activity에 키보드가 열릴 때의 크기 조정을 지정했다.
- 시설 패널을 열 때 지도 연결 상태를 내려놓고, 행사장 상세는 휴대폰에서 독립 창으로 연다. 장소를 선택하면 진행하던 질문창으로 돌아갈 수 있다. 시설 출처와 참고 안내는 상세에 표시한다.
- 짧은 가로 터치 화면도 모바일 배치를 사용한다. 도보·교통 경로는 결과 패널의 높이가 정해진 뒤 보이는 지도에 맞춘다. 저장 목록이 비어 있으면 길 찾기로 돌아갈 수 있고, 제보는 기본 화면의 입력 상태를 보존한다.

Android 1.0.5의 공개 빌드에는 고정 API 키가 없다. 이전과 같은 패키지와 서명을 사용하며 개인 Gemini 키가 비어 있으면 서버 설정을 사용한다.
