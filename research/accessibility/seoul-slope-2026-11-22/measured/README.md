# 서울 보도 실측 및 접근성 자료 확인

자료 요청 및 내부 검증 기준일은 2026-11-22(KST)다. 현장 실측 여부는 자료 생산자가 명시한 원 조사 방법이다. 동행길 현장 검증 또는 경로 안전 판정은 수행하지 않았다.

## 확보한 보도 실측

MIT Senseable City Lab의 Seoul Sidewalk Accessibility Image Dataset 최신 공개판은 2026-09-23 게시됐다. 원 조사일은 2026-07-07·08·10·11이다. 사진 514장에 연결된 CSV 514행의 위도·경도, 보도 유효폭, 종단 경사, 횡단 경사와 포장 등급을 확인했다. 위·경도 쌍은 513개다. 자료의 좌표계나 측위 오차 규격은 CSV와 제공 절차서에서 확인되지 않는다. 자치구 대조에는 서울 25개 자치구 기존 OSM 경계와 경위도 점을 사용했다. [Zenodo 최신 자료](https://doi.org/10.5281/zenodo.22908353) [원 연구와 현장 조사 방법](https://arxiv.org/html/2609.17882v1#S4.T2)

| 비교 항목 | 결과 |
| --- | --- |
| 서대문구 | 297행, 고유 좌표 296개 |
| 관악구 | 118행, 고유 좌표 118개 |
| 강서구 | 99행, 고유 좌표 99개 |
| 나머지 22개 자치구 | 표본 0행 |

| 종단 경사 | -9.3~11.8°, 중앙값 0.0° |
| 횡단 경사 | -9.7~8.0°, 중앙값 0.3° |

연구진은 보도 노면에서 진행 방향과 폭 방향 기울기를 각각 실측했다. 두 경사 필드의 원 단위는 도(°)이며 경사율은 필요할 때 `100 × tan(각도 × π/180)`으로 별도 계산한다. 횡단 경사의 부호는 조사자가 정의한 좌우 방향을 따른다. 도로망의 진행 방향이나 최대 경사값으로 바로 옮길 수 없다.

논문 사전공개판 표에 든 서울시니어스타워 99장과 실로암 118장의 행정구 표기는 좌표 점 집계와 일치하지 않는다. 자치구 집계에는 개별 좌표를 사용했다. 포장 등급에 관해서도 논문 v1은 한 명의 평가자로 서술하며 최신 데이터 페이지는 세 평가자와 다수결을 안내한다. 경사 실측 설명과 단위는 각각 최신 데이터와 제공 절차서 기준이다.

CC0-1.0으로 공개된 원본 CSV와 절차 ZIP에 대해 HTTP 200 응답, 게시 MD5, ZIP 무결성을 확인했다. 이미지 3묶음 약 4.6GB는 파일 목록만 확인했다. `verified-measurements.json`에 원본 SHA-256과 비교 기준 경계의 해시가 있다. `verify_measured.py --boundaries 경계.geojson`으로 재현할 수 있다.

## 경사값과 구분한 공개 자료

- **서울교통공사 휠체어경사로 설치 현황 OA-13116**. 최신 목록의 2024-03-31 CSV를 공식 파일 서버에서 내려받았다. CP949, 11,318바이트, SHA-256 `5246f45a70a9773e8c6db3ca84074e3a12626e0783df0c9dc0ced94116fc88ef`. 서울교통공사 1~8호선에서 506행과 253개 호선·역명 조합을 확인했다. 외부 E/V 260행, 외부출입구 122행, 대합실 97행, 내부 E/V 17행, 승강장 10행이다. 필드는 호선·역명·구분·위치이며 기울기, 고저차, 길이, 위경도는 없다. 공공누리 제3유형이므로 원본 참조로 분류한다. [공식 파일 목록](https://data.seoul.go.kr/dataList/OA-13116/F/1/datasetView.do)
- **서울시 장애인편의시설 목록 OA-23030**. 2026-11-21 갱신 표시. 소개문에 경사로 등 설치 여부를 설명하지만, 실제 Sheet 헤더 및 3행 응답의 데이터 스키마에는 시설명·주소·위도·경도·시설유형·영업 상태 같은 기본 정보만 있고 경사로 설치 여부나 수치 항목이 없다. 응답의 전체 선언 건수는 29,153행이며 전량을 받은 것은 아니다. 대표자명 필드가 있어 검증한 원시 응답은 공개 묶음에서 제외한다. 포털 표기는 이용허락범위 제한 없음이다. [서울시 목록](https://data.seoul.go.kr/dataList/OA-23030/S/1/datasetView.do) [연계 한국사회보장정보원 API](https://www.data.go.kr/data/15092317/openapi.do)
- **한국소비자원 서울·경기 공공복지·문화시설 설치 실태**. 2017년 공개. 50곳의 접근로·주출입구를 조사했고 접근로가 있던 43곳 중 31곳, 주출입구 경사로를 설치한 36곳 중 26곳에서 당시 조사 기준의 경사도를 초과했다. 오래된 수도권 표본의 집계이며 서울 보도 구간별 좌표·수치 데이터는 확인되지 않는다. [공식 조사 결과](https://www.kca.go.kr/home/sub.do?menukey=4002&mode=view&no=1002009528&page=41)
- **서울연구원 GeoAI 정밀진단 기반 연구**. 2025-07-09 발간, 과제번호 2024-BR-10. LiDAR·거리뷰 등 방법과 정책 근거를 공개했다. 서울시 보도 실측 경사 전수 원자료의 재배포 경로는 확인되지 않았다. 공식 페이지의 본문 이용 표기는 출처표시·상업적 이용 금지·변경금지다. [서울연구원 연구보고서](https://www.si.re.kr/bbs/view.do?key=2024100039&pstSn=2507150001)
- **서울시립대 캠퍼스 경로 연구**. 2023 지리학대회 초록집에서 서울시립대학교 캠퍼스 내 휠체어 경로를 위해 현장 측량 및 경사도·볼라드·도로턱·계단 분류를 수행했음을 확인했다. 원시 수치·노드링크 다운로드와 재이용 조건은 확인되지 않았다. [학술대회 초록집](https://www.spacein.kr/data/bbs/147/2023%EC%A7%80%EB%A6%AC%ED%95%99%EB%8C%80%ED%9A%8C%EC%B4%88%EB%A1%9D%EC%A7%91.pdf)
- **BF 인증 현황**. 인증심사기준에는 접근로 기울기 평가 항목이 있다. 한국장애인개발원 전국 CSV 설명의 공개 열은 시설명, 인증번호, 등급 등 인증 기록이며 접근로 실측 기울기는 없다. [전국 BF 인증 현황](https://www.data.go.kr/data/3051093/fileData.do?recommendDataYn=Y) [BF 인증 제도](https://www.koddi.or.kr/bf/info/bf.do)
- **서울시 보행자 출입구 OA-21699**. 공간 ZIP과 항목 정의서 HWPX의 HTTP 200 원본을 확보했다. 원본 Shape Point의 실제 수는 16,786점이다. 정의서 요약의 14,454건과 다르다. 실제 SHP의 EPSG:4326, 전체 `refDate` 2022-11-23, DBF 수정 2022-12-15, 포털 게시 2023-01-16과 갱신 2023-04-21을 각각 확인했다. 서울 25구 OSM 경계와 대조해 25개구 내부 16,741점과 경계 밖 45점을 구분했다. 법정 행정경계 재검증은 수행하지 않았다. 포털 표기는 이용허락범위 제한 없음이다. [공식 파일 목록·스키마](https://data.seoul.go.kr/dataList/OA-21699/F/1/datasetView.do) [공간 ZIP 원본](https://datafile.seoul.go.kr/bigfile/iot/inf/nio_download.do?useCache=false&infId=OA-21699&seqNo=&infSeq=3&seq=1) [정의서 원본](https://datafile.seoul.go.kr/bigfile/iot/inf/nio_download.do?useCache=false&infId=OA-21699&seqNo=&infSeq=3&seq=20)

  - 공간 ZIP 2,486,018바이트 및 SHA-256 `cfcce59f1d61f6fd2393130b86a97a6b785f27134f1059f38451ba84fb82d933`. 정의서 88,727바이트 및 SHA-256 `e057f77b97faece8e8b48bef6a1deae552d437e771e144c929df18f54bb1fb35`. 공간 ZIP의 한글·영문 컬럼판을 중복 집계하지 않고 영문 컬럼판을 분석했다.
  - 경사로 설치 `ER_Y` 1,856점, 미설치 `ER_N` 14,857점, 미기재 73점이다. 시설 진입부의 분류값 `ED_EC` 603점은 정의서 코드표에 5° 이하 접근 가능 경사로 명시된다. `ED_ED` 1,811점은 계단 단독 설치 또는 5° 초과·접근 곤란 경사를 함께 나타낸다. `ED_EA` 수평 접근 7,067점, `ED_EB` 경사로나 리프트 등 설치 692점, `ED_EX` 기타 55점, 미기재 6,558점이다. 계단인지 경사인지 별도 검증이 필요한 사례의 기울기는 미확인으로 둔다.
  - 별도의 구조화된 경사 수치 필드는 없다. 비고 `etc`에서 ‘경사’와 숫자 각도·퍼센트 단위를 함께 포함한 41행을 확인했다. 출입구를 지난 내부 경사, 구간 범위, 복수 수치와 상한 초과 표현을 구분해야 한다. 각 비고의 측정 도구·수평거리·도로망 대응은 확인되지 않았다. `entrance-district-audit.json`에 구별 집계와 자유서술 확인 건수를 보존했다.
