시험점은 환경부 응답 범위·형식을 살피려고 선택한 좌표다. 한강 수면 비교점에도 5도 미만이 반환되므로 이 등급을 보도 경사·교량 접근성으로 해석할 수 없다. 5°는 경사율 약 8.75%에 해당하며, 범주의 하한·상한을 알고 있어도 특정 보도 구간의 종·횡단 값을 역산할 수 없다. 숫자와 원 응답 SHA-256은 [지점 응답 요약](neins-seoul-sample.json), API 접근 여부는 [접근 상태](metadata-http-checks.json)에 기록했다. 원응답은 내부 대조용으로 확보했다.

## 확보 기준

국토정보플랫폼 접근이 가능한 환경에서는 서울 1:1,000 공개 도엽 색인과 5m DEM 도엽을 내려받아 25개 구 경계와 교차한 피복률을 계산한다. 도엽별 격자간격·제작일·수평·수직 기준·해시를 확인한다. 필요하면 NGII 국토조사과의 1m 자료 제공 경로를 별도로 확인한다. 좌표계, 표고 기준, 선행 도형, 시점 검사를 통과해도 DEM과 등고선은 지표 추정 출처로 기록한다. 현장 실측과 연결이 없는 교량·터널·층위·경사로에는 지표 기울기를 대입하지 않는다.

## 기타 국가기관 지형·도로 자료

- 한국임업진흥원 임업정보 다드림은 산림청 지형정보의 표고·방위·경사도, 축척 1:5,000, 자료 기준 2022년 및 범위 ‘구축지역’을 명시한다. 서울 전체의 도심 보행로 피복과 다운로드 원본은 확인되지 않았다. [임업정보 다드림 주제도 목록](https://www.kofpi.or.kr/intro/bizGuide_02_06.do)
- 국토지리정보원 정밀도로지도(15059912)는 차로중심선·도로시설을 포함하는 3차원 자율주행용 자료다. 카탈로그 표시 도로망과 실제 서울 도엽 확보, 각 선형의 Z축과 높이 기준은 구분한다. 이 조사에서는 서울 원본을 다운로드하지 못했다. [정밀도로지도 공식 카탈로그](https://www.data.go.kr/catalog/15059912/fileData.json)
- 국토환경성평가지도의 도엽별 TIFF 다운로드 안내는 환경평가 지도 출력을 설명한다. 이 안내만으로 기울기 분류 래스터 또는 5m 입력 DEM의 공개 배포가 확인되지는 않는다. [도엽 다운로드 안내](https://ecvam.neins.go.kr/contents/doyupList.do)
